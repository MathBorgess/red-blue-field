# Fluxo de agentes

O fluxo atual usa o Codex local para apoiar as atividades de [RED](../RED/README.md) e [BLUE](../BLUE/README.md). O laboratório mantém execução manual e roteiros conhecidos no [FieldDesk](running-the-lab.md).

Os antigos chats próprios Red e Blue, baseados em Deep Agents e proxy, foram retirados da organização atual. A documentação e os registros de validação anteriores descrevem aquela implementação histórica; não comprovam o fluxo atual. O histórico Git preserva a versão anterior deste guia.

A implementação MCP permanece no núcleo, mas a conexão ao cliente ainda requer validação específica. Veja [MCP Red e Blue](mcp-red-blue.md).
