# FIELD

Área de alvos e cenários de estudo.

- [Northstar Tasks](codex-security-client-app/README.md): aplicação sintética para revisão estática. A licença e a proveniência estão na própria pasta. Executá-la exige ambiente isolado e escopo apropriado ao exercício.
- **FieldDesk**: aplicação e cenários do laboratório Python compartilhado em `red_blue_field/` e `scenarios/`. Veja o [guia de execução](../docs/running-the-lab.md).
- [SPIFFE/WIF + OPA no FieldDesk](spiffe-wif-lab/README.md): bancada opcional de identidade de workload, troca de tokens e autorização de leitura/inserção com dados sintéticos.

Cada exercício deve identificar a revisão do alvo, ações permitidas e evidências necessárias. Manter os resultados privados fora deste repositório público.
